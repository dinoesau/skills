# Prose Reference

Read only the section matching the detected regime, plus section 5 for handoffs.

## 1. Voice regimes

| Regime | Voice | Adjectives | Stance |
|---|---|---|---|
| Academic | Impersonal where expected: "the analysis shows", "results suggest". First person only if the venue allows it. | Neutral and checkable: "statistically significant", "with methodological limits". | Hedged to the evidence. |
| Explanatory | Warmer, direct address allowed. | Concrete over ornamental. | Confident guide, defines terms early. |
| Opinion | First person allowed for ownership. | Strong but sourced: no "wonderful" or "unsustainable" without the number or reason attached. | Clear position, fair counter. |

## 2. Hedging and precision

- Hedge verbs for claims beyond direct evidence: suggest, indicate, appear, seem, tend to.
- Replace absolute adverbs such as always, never, proves with bounded versions unless the evidence warrants them.
- One stable meaning per key term within a passage. Define on first use, repeat the same term.
- Generalizations carry their scope: who, where, when, how many.

## 3. Connectors by function

- **Cause:** therefore, consequently, as a result.
- **Contrast:** however, nevertheless, by contrast, although.
- **Addition:** moreover, furthermore, likewise, similarly.
- **Sequence:** first, next, finally, subsequently.
- **Example:** for instance, namely, in particular.

Rules: one connector per transition, vary across consecutive paragraphs, never stack two connectors for one move.

## 4. Vice catalog

| Vice | Example | Repair |
|---|---|---|
| Pleonasm | "absolute certainty", "future prospects ahead" | Cut the redundant word. |
| Nominalization chain | "the realization of the implementation of the process" | Verbalize: "we implemented the process". |
| Stacked subordinates | Three nested clauses in one sentence | Split into two sentences at the clause boundary. |
| Repeated connector | "Moreover" opening three paragraphs | Rotate by function from section 3. |
| Paragraph pile-up | Three ideas in one block | One idea per paragraph, strong first sentence each. |
| Emotive adjective | "a marvelous result" | The measured value plus its significance. |
| Undefined jargon | Arcane term with no payoff | Define on first use or replace with plain term. |

## 5. Rhythm guide

- Alternate sentence lengths: follow a long explanatory sentence with a short concluding one.
- Split sentences over 30-35 words unless the length carries a deliberate enumerative purpose.
- Read transitions aloud in spirit: if two paragraphs jar, add a bridge sentence restating the thread, not a bare connector.
- Keep lists parallel in grammar and length.

## 6. Handoffs

- Fallacy, invalid form, ambiguous concept goes to the `logic` skill with the quoted passage.
- Missing abstract, methods, references, or section order problem goes to the `paper-craft` skill with the section name.
- State the handoff explicitly so the user knows style work paused for a substance or structure fix.
