# Skills

Skills de IA para desarrollo con agentes de codigo.

## Instalacion

```bash
npx skills add dinoesau/skills
```

## Skills incluidas

| Skill | Descripcion |
|---|---|
| `to-plan` | Plan de implementacion agente-ready: PRD + instrucciones ejecutables para el agente |
| `plan-critique-loop` | Revision adversarial de planes con 3 agentes en paralelo hasta aprobacion |
| `git-commit` | Creacion de commits convencionales agrupados por dominio |
| `coding-guide` | Guia de codigo: pensar antes, simplicidad, cambios quirurgicos, objetivos verificables |
| `bloodhound-antipatterns` | Detector de code smells y anti-patrones (catalogo refactoring.guru) |
| `rusty` | Modelado de dominio funcional en Rust: parse-don-t-validate, newtypes, thiserror vs anyhow, type-state |
| `good-typescript` | Modelado de dominio funcional en TypeScript: parse-don-t-validate, branded types, Zod, errores estratificados |
| `good-python` | Modelado de dominio funcional en Python: parse-don-t-validate, value objects, Pydantic, errores estratificados |
| `ai-engineering` | Guia de implementacion para apps de IA: agentes, chatbots, RAG y features con LLM |
| `logic` | Estructura argumentos en premisas y conclusion, valida razonamiento y detecta falacias |
| `paper-craft` | Estructura ensayos y articulos a estandar peer-review: IMRaD, PRISMA, citas |
| `prose` | Pule prosa academica y explicativa: claridad, tono, ritmo y cohesion |
